# Source images

Place your input PNG files in this directory when working locally.

Most files in this directory are intentionally ignored by Git so you can keep private or licensed sticker sheets out of the public repository.

The repository keeps one published sample input image, [`hug.png`](hug.png), so visitors can see a real source example on GitHub.

Expected format:

- `.png` files
- white or near-white page background
- one sticker image per file
